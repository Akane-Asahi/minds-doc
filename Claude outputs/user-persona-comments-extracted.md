# Document text

Who Jamie Is

Jamie Chen, 21, third-year Bachelor of Environmental Science, State University. Diagnosed with dyslexia at age 8 (mild–moderate); uses screen reader and text-to-speech. A competent, motivated searcher who has adapted to digital research tools over 13 years who isn't someone unfamiliar with technology; it's someone whose working memory is taxed by the process of multi-session research itself.

Cognitive Profile

Working memory

Holds roughly 3–4 items simultaneously (typical for dyslexia; Choi & Arguello, 2025)

Cannot reliably hold task goal + current query + found results + prior-session context in mind all at once

Loses the search thread after ~30 minutes of browsing, or after any interruption (Li et al., 2020)

Reading & processing

Reads at ~60% of typical speed, but with high accuracy (Duranovic, 2018)

Text-heavy screens cause fatigue; visual categorization and color-coding reduce load

Numbers read as text:  "72%" costs the same working memory as "seventy-two percent"

Prefers sans-serif fonts, increased spacing, low visual clutter (Rello & Baeza-Yates, 2016; Morris et al.)

Metacognition

Strong metacognitive awareness when supported: can articulate goals, spot off-topic results, notice gaps in what's been covered

Metacognition becomes effortful the moment it has to compete with holding search state in memory at the same time (dual-task interference)

Thrives when the interface externalizes planning/monitoring state, freeing working memory for the actual search decisions (Crescenzi et al., 2021)

The Task

4,000-word research paper for Environmental Science 301 (Senior Seminar): "How does green space access relate to environmental justice in North American cities?" Genuinely multi-disciplinary (ecology, urban planning, sociology, policy) — not a lookup task, and not resolvable in one sitting.

How the Search Actually Unfolds



Reacquaintance cost: about 20% of total session time goes to reconstructing prior state rather than making new progress (Hoeber, Islam et al., 2024).



Pain Points → What the System's AI Does About Each One

The four pain points below are exactly the four things the AI in the system is responsible for (see ai-goals-in-system.md for the full rationale on each):

Jamie doesn't know how to break a broad goal into a workable plan. → AI proposes sub-goals from the stated search goal + what's already known, so Jamie reacts to a first draft instead of generating the decomposition from nothing.

A poorly-phrased query gets bad results, and Jamie won't always know why. → AI generates the actual search queries behind each chosen sub-goal, removing query formulation as a competing demand on working memory.

Reading every result to judge relevance is the most expensive step, cognitively. → AI match-scores results so Jamie can decide whether to save something without reading it first — reading is deferred entirely to a later, dedicated pass.

Returning after a gap, Jamie has to rebuild the whole mental picture from scratch. → AI-generated recaps and visual summaries reinstate the goal, what was found, and why — the same effect as recalling something faster in the room where you learned it — so Jamie resumes mid-thought instead of starting cold.

Strengths (worth keeping in the frame)

Highly motivated; researches thoroughly once supported

Strong visual-spatial reasoning; responds well to visualization and color-coding over dense text

Already self-aware about working-memory limits and proactively reaches for external aids (notes, screen reader, accessibility settings)

One-Page / Presentation Version

Who: Third-year environmental science undergrad, dyslexia (mild–moderate), comfortable with digital tools.

Search profile: Cross-session exploratory research, 60–120 min sessions, 2–7 day gaps, 8–15 results reviewed and 4–6 saved per session. Topic is complex and multi-disciplinary, genuinely requiring several sessions to make sense of.

Constraint: ~3–4 items in working memory at once (Choi & Arguello, 2025); loses the thread after ~30 min or any interruption (Li et al., 2020).

Cost today: ~20% of session time lost to reacquaintance after a gap (Hoeber, Islam et al., 2024); text-heavy interfaces add fatigue on top of that (Rello & Baeza-Yates, 2016).

What the system does: AI handles sub-goal planning and query formulation up front, lets Jamie save without reading via match scores, and reinstates context on return via recaps and visuals — so working memory stays free for the actual thinking, not for holding the process together.
