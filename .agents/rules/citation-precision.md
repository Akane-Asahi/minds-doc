# Citation Precision Rules
- ALWAYS use numerical bracket format (e.g., [1], [3, 7]).
- NEVER use (Author, Year) format.
- PLACE citations immediately after the terminology or specific claim they support.
- ONLY use citation keys found in the 'references.bib' file in the root directory.
- If a claim is supported by multiple papers in the library, cite all relevant keys.
